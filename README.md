# Stewart Squad Adventure — Lights in the Dark

A family time capsule you can play. Liam, Noah, Collette, and Isabella are the heroes; Grandpa Ed flies the biplane. This repo rebuilds the original single-file Canvas game (v27, in `docs/legacy/`) as a low-poly 3D action RPG with Three.js and TypeScript.

- **The brief:** [`docs/BRIEF.md`](docs/BRIEF.md) — read it in full first.
- **Where we are:** [`docs/NEXT_SESSION.md`](docs/NEXT_SESSION.md) and [`docs/PROGRESS.md`](docs/PROGRESS.md).
- **How sessions run:** [`docs/SESSION_PLAN.md`](docs/SESSION_PLAN.md).

## Run it

```bash
npm install
npm run dev
```

`npm run check` runs typecheck, lint, and unit tests. `npm run build:archive` produces the single-file time-capsule HTML in `dist-archive/`.

A kid-facing "How to play" lands here at release (Phase 6).
