# Mockup log (Phase 0.75 visual studies)

One line per iteration: study · iteration · what changed · verdict. Verified library shapes (Rule 2) go at the top of the study that first used them. Working notes and the reasoning behind each change: `STUDY_NOTES.md`. Numbers of the current frames: `style-draft.json`.

**How to run a study:** `npm run dev`, then `http://localhost:5173/sandbox/forest-dusk/?shot=S1&t=dusk&v=B` (`shot` S1–S4 are the bible's stations, `W1` wide, `L1` lower pitch, `D1` diorama, `CU` close-up, `CF` fireside; `t` noon | golden | dusk | night; `v` A | B | C; `curve` 0–3; `post=0` raw; `ui=0` hides the number overlay; `freeze=1` stills motion). ### Scene 2 — Home, Wrong (open brief 3.2; `sandbox/shadow-wrong/`, id `shadow`)

The camp is not rebuilt: `forest-dusk/terrain.ts`, `scatter.ts` and `props.ts` are imported and the whole tree is pushed through `voidify()`, which maps every vertex colour to ash-by-luminance pushed into the void's violet and zeroes every `aEmissive`. The wrong things are then added on top. **Decision, logged (the brief was silent):** the shard is *not* mirrored geometrically. A mirror the player never sees beside the original is a transform nobody can read; the mirror is carried by the palette, the cold fire, the ember windows, the torn tent, the upside-down crest, the swing that swings by itself, the stream that climbs, and the one warm light below the rim — all of which read in a single still.
