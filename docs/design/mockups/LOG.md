# Mockup log (Phase 0.75 visual studies)

One line per iteration: study · iteration · what changed · verdict. Verified library shapes (Rule 2) go at the top of the study that first used them. Working notes and the reasoning behind each change: `STUDY_NOTES.md`. Numbers of the current frames: `style-draft.json`.

**How to run a study:** `npm run dev`, then `http://localhost:5173/sandbox/forest-dusk/?shot=S1&t=dusk&v=B` (`shot` S1–S4 are the bible's stations, `W1` wide, `L1` lower pitch, `D1` diorama, `CU` close-up, `CF` fireside; `t` noon | golden | dusk | night; `v` A | B | C; `curve` 0–3; `post=0` raw; `ui=0` hides the number overlay; `freeze=1` stills motion). ### Scene 2 — Home, Wrong (open brief 3.2; `sandbox/shadow-wrong/`, id `shadow`)

The camp is not rebuilt: `forest-dusk/terrain.ts`, `scatter.ts` and `props.ts` are imported and the whole tree is pushed through `voidify()`, which maps every vertex colour to ash-by-luminance pushed into the void's violet and zeroes every `aEmissive`. The wrong things are then added on top. **Decision, logged (the brief was silent):** the shard is *not* mirrored geometrically. ## The shared runtime for the Opus fixes (2026-09-08)

Brief: `docs/qa/briefs/opus-fixes-runtime.md`; rule sheet: `docs/qa/rules/opus-fixes-runtime.md`. Four changes to `sandbox/_shared/`, nothing else; no scene folder touched.

**The four changes**

1. **`step.ts`, the stepping harness.** `installStep(api)` is called once at the end of `runScene` and puts `ssStep(n)` (renders exactly n frames of 1/60 s through the normal `renderOnce`, returns the scene clock), `ssSnap(name)` (one frame, then `saveShot` under a lowercase name with the card overlay when the card is shown), `ssKey(k)` (a `keydown` `KeyboardEvent` on `window`) and `ssTHREE` on the page. `?step=1` (new `Params.step`) turns off the hidden-tab `setInterval` and hands the rAF loop `dt = 0`, so the clock moves only under `ssStep`. `scene.ts` also exposes the live `SceneCtx` as `ssCtx`.
2. **The `look` hook.** `SceneWorld.look?(kid, active)` is consulted for every *non-active* kid before the rig reads `lookAt`; a returned vector is copied in, `null` keeps the default (the active kid's head). The active kid's `poi` rule is unchanged. Both hooks are documented in the interface — scene code may not write a non-active kid's `lookAt` itself, because the runtime overwrites it every frame.
3. **The hit-stop (T-31).** `ctx.stop(seconds)`, `ctx.stopped`, `ctx.stopDt`. While the timer runs, `walk.update`, every `k.update` and `world.update` are handed `dt = 0`; `t` and `ctx.stopDt` keep the wall dt, which is the channel a scene reads to step whatever it exempts (the hit itself, its debris). The timer takes the max of any overlapping stops and is not rounded: 0.04 s is two frames.
4. **`readParams()` (T-29).** `readParams(defaultT = 'dusk')`. `scene.ts` calls `readParams('')` and treats any `t` not in `def.times` as `def.defaultTime`; the Forest scene's own `readParams()` is unchanged and still sees `dusk`.

**The harness** (`PRE_BUILD_TODO.md` P-02): `node scripts/sandbox-drive.cjs "<url>" scripts/probes/<probe>.cjs` launches the installed Chrome headless through `puppeteer-core` 25.10.0, waits for `ssWorld` (or `ssSave`, for the Forest), and hands the probe `step / snap / key / hud / evaluate / sleep`. Probes kept: `runtime-step.cjs`, `runtime-look.cjs`, `runtime-stop.cjs`, `runtime-frames.cjs`.
