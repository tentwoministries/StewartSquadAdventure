# Mockup log (Phase 0.75 visual studies)

One line per iteration: study · iteration · what changed · verdict. Verified library shapes (Rule 2) go at the top of the study that first used them. Working notes and the reasoning behind each change: `STUDY_NOTES.md`. Numbers of the current frames: `style-draft.json`.

**How to run a study:** `npm run dev`, then `http://localhost:5173/sandbox/forest-dusk/?shot=S1&t=dusk&v=B` (`shot` S1–S4 are the bible's stations, `W1` wide, `L1` lower pitch, `D1` diorama, `CU` close-up, `CF` fireside; `t` noon | golden | dusk | night; `v` A | B | C; `curve` 0–3; `post=0` raw; `ui=0` hides the number overlay; `freeze=1` stills motion). ### Scene 2 — Home, Wrong (open brief 3.2; `sandbox/shadow-wrong/`, id `shadow`)

The camp is not rebuilt: `forest-dusk/terrain.ts`, `scatter.ts` and `props.ts` are imported and the whole tree is pushed through `voidify()`, which maps every vertex colour to ash-by-luminance pushed into the void's violet and zeroes every `aEmissive`. The wrong things are then added on top. **Decision, logged (the brief was silent):** the shard is *not* mirrored geometrically. Brief: `docs/qa/briefs/reel-fixes-rocks-03.md`; rule sheet: `docs/qa/rules/reel-fixes-rocks-03.md`; row **T-43**. **The defect, measured before writing a line (Working Rule 2, one `node -e` against the installed three r185).** `new THREE.IcosahedronGeometry(1, 1)`: `index === null`, **240** position vertices over **42** exactly-unique positions (80 faces × 3); detail 3: **960** vertices over **162** positions; `SphereGeometry` by contrast is indexed. **The fix.** `displace(geo, r, { x, y, z, lockXZ? }, tol = 1e-4)` groups vertices by quantised position, draws one scale per group (x, then y, then z — `lockXZ` gives x and z the same draw, which is what the caves' shell did), applies it to every copy and recomputes the flat normals. The geometry stays non-indexed, the vertex count is unchanged and the faceting is the same: §0 rule 3's one value per face is untouched. `openEdges(geo)` counts the undirected edges (between unique positions) not shared by exactly two faces — 0 on a closed surface.
